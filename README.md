Multi-Game Arcade
Welcome to the Multi-Game Arcade! This is a simple, interactive command-line application featuring three classic mini-games. Built to be lightweight and engaging, it's a great way to kill some time or test your general knowledge.

Games Included
Number Guessing Game: Can you beat the odds? Guess the randomly generated number within a set number of attempts.
Rock, Paper, Scissors: The ultimate classic. Face off against the computer AI and see who dominates.
General Knowledge Quiz: Test your brain! Answer a series of trivia questions across various topics and check your final score.
Features
Interactive Menu: Easily switch between games using a centralized main menu.
Smart Validation: Prevents crashes by handling invalid user inputs gracefully.
Score Tracking: Keeps track of your performance during the quiz and game rounds.
Replayability: Option to replay any game immediately without restarting the entire application.
